    Working in your ArchiCAD 25 Solo template

    Four facts about your studio standard that shape how files move between us.

    Back-saving goes one version at a time
    A file made in Archicad 28 saves back only to 27. Work for you is drawn in 25 from the start, never saved down from a newer version.
    New licenses start at version 26
    Graphisoft's cloud licenses run Archicad 26 and later. Running 25 takes a key-based license, which new customers could buy only until December 31, 2024.
    Solo has no Teamwork, Cinema 4D rendering or Hotlinks
    Typical details live in your template's favorites and view map rather than in hotlinked modules, and work comes back as whole .pln files. File names and revisions carry more weight because of it.
    Publisher can name the files
    Publisher items can be renamed by layout ID, name or a custom name, so the exported PDFs follow your file-naming standard without hand-renaming.

    How a set comes back to you

    1. Redlines logged

      Designer plans and redlines arrive in Telegram. Each redline is logged against its sheet so none is missed.

    2. Drafted in your template

      Plans, ceiling plans, elevations, sections and millwork details, in your layers, pens, favorites and title block.

    3. Checked before it is sent

      The Publisher set exports the PDF and Set Check reads it. Every finding is fixed in the model, never in the PDF.

    4. Posted with a note

      The PDF, the .pln and the check report go into the thread with a short list of what changed since the last issue.
